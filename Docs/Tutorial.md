# 튜토리얼 시스템

## 개요
- 게임의 초보자가 어떻게 게임을 하는지 이해하는 것을 돕는 시스템


## 기획 요청 사항 요약
- 발동 조건
  - 세이브 파일이 없을 때 플레이하면 자동으로 나오고, 세이브 파일이 하나라도 있다면 나오지 않도록 구현

- 튜토리얼의 형태
  - 텍스트 + 관련 이미지의 UI 형태로 나와야함
  - 튜토리얼 UI는 5페이지가 있고, 스마트폰 화면의 좌측 절반을 클릭하면 앞선 페이지로 가고, 우측 절반을 클릭하면 다음 페이지로 넘어감
  - 튜토리얼 중에는 다른 기능과 상호작용이 되면 안됨
  - 마지막 페이지 이후, 다음 페이지로 넘어가면 튜토리얼 종료

- 기타 제반 사항
  - 세이브 파일을 모두 삭제하는 것 이외에 튜토리얼 시스템에 대한 '다시보기' 기능이 필요하지 않음
  - 튜토리얼 시스템을 응용하여 다른 설명 시스템에 재사용할 예정은 없음


## 구성 요소
- 튜토리얼 전용 기능
  - **TutorialCanvas** : 튜토리얼 UI와 UI 작동 제어를 담은 게임 오브젝트.  `MainScene`에 존재
  - **TutorialManager.cs** : 튜토리얼의 시작, 페이지 넘어가기, 종료 등 기능을 관리. ServiceLocater에 등록하여 전역 접근
  - **TutorialUIController.cs** : 튜토리얼의 패널 On / Off 하고, 버튼 동작들을 연동
  - **TutorialUIRenderData.cs** : 튜토리얼 작동에 따른 액션 콜백을 진행
  - **TutorialUIRenderer.cs** : 튜토리얼 하위 패널에 붙어서 On / Off 명령을 받고 실행

- 기존 기능
  - **ServiceLocater.cs** : 튜토리얼의 각 기능을 주고 받는 서비스를 중앙에서 전역 관리
  - **GameManager.cs** : 튜토리얼 실행 여부에 대한 데이터를 저장 및 제공
  - **SlotUIController.cs** : `SlotScene`에서 슬롯이 하나라도 있는지 여부를 판단


## 작동 방식
1. `SlotScene`의 **SlotUIController.cs**에서 세이브 파일이 있는지 여부를 판단
2. 세이브 파일이 하나도 없다면 **GameManager.cs**의 IsNeedTutorial 프로퍼티에 True / 하나라도 있으면 False를 저장
3. `MainScene`으로 넘어가면 **TutorialCanvas**에 있는 **TutorialManager.cs**가 자동 실행. True면 튜토리얼 동작 / False면 튜토리얼 동작 안하고 종료
4. 튜토리얼 동작시, **TutorialCanvas**의 MainPanel이 활성화되며 튜토리얼 시작. 모달 창이 포함되어 다른 기능과 상호작용 불가
5. 화면의 우측 절반 클릭 시 다음 페이지로 넘어감, 좌측 절반 클릭 시 이전 페이지로 돌아감. 총 5페이지가 있음
6. 마지막 페이지에서 우측 절반 클릭 시 MainPanel 비활성화 및  **GameManager.cs**의 IsNeedTutorial 프로퍼티가 False가 되며 튜토리얼 종료.
