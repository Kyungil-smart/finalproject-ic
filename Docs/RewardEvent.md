# RewardEvent 시스템

## 개요
- 프리, 풀 프로덕션 세부프로세스 종료시 마다 이벤트 발생
- 페이즈 종료시 달성한 지표값을 산출하여 이벤트 발생
- Avg_Level은 투입한 직원의 평균 레벨
- 각팀의 지표달성(Target)의 달성 비율에 따라 보상 차등 지급

## 동작 방식
1. 프리, 풀 프로덕션의 세부프로세스 종료
2. 지표값을 산출하여 이벤트 발생
3. 각 팀 지표 달성 비율에 따라 보상 선택
4. UI 표시 및 버튼 클릭 대기
5. 보상 차등 지급

## 지표 달성 기준(예시)
| 등급 | 조건 |
|------|------|
| 1성  | 1% ~ 49% |
| 2성  | 50% ~ 79% |
| 3성  | 80% ~ 100|

## 주의 사항
- 프리, 풀 프로덕션의 세부 단계마다 이벤트 호출이 되므로 호출이 잦음(6번).
- 마지막 퀄리티 산정이 끝날때 까지 지표가 초기화 되면 안됨.
- 각 팀(기획, 개발, 아트) 마다 계산이 되어야 함(현재는 계산식 동일).
- 투입된 직원들의 메인 스탯과 서브스탯을 알 필요가 있음(기획이면)(기획수치, 커뮤니케이션 수치)등등.
- 해당 프로세스에 새로 투입된 인원만 스탯 계산(2명).
