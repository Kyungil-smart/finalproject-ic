# 핵심 기술 아키텍처 - 이벤트 시스템

1. 전체 흐름
이벤트 시스템은 데이터 로딩, 이벤트 실행, 보상 처리 세단계로 구성되며, 데이터 로딩은 초기 실행시 한번만 이루어집니다.
- EventDataLoader가 구글시트에서 이벤트 데이터를 다운로드하고 ScriptableObject에 캐싱합니다.
- EventManager는 이벤트 호출 시 이벤트 종류(Enum)에 맞는 TaskRunner를 선택하여 실행합니다.
- TaskRunner 실행 완료 후 EventRouter가 보상 처리르 담당합니다.

흐름도 :
```
DataLoader (구글 시트)
    ↓  초기 다운로드 & ScriptableObject 캐싱
EventManager
    ↓  이벤트 종류에 따라 TaskRunner 선택
TaskRunner  (Regular / Staff / Achieve)
    ↓  보상 처리 위임
EventRouter  (string 키 → 보상 딕셔너리)
```
---

2. EventRouter - 보상 설계
- 보상 이름(string)을 키로 하는 딕셔너리에 각 보상 처리 함수를 등록해두고, 이벤트 데이터의 보상 키값에 따라 해당 함수를 실행합니다.
- 보상 종류가 추가되더라도 딕셔너리에 키-값 한쌍만 추가하면 되므로 확장성이 높습니다.
예시 :
- "Money" -> 재화 증감 처리
- "Quality" -> 퀄리티 증감 처리

---

3. 오프라인 동작 구조
최초 실행 시에만 인터넷 연결이 필요하며, 이후에는 ScriptableObject에 캐싱된 데이터로 오프라인 환경에서도 정상 동작합니다.
