# Folder Guide

## Docs 폴더 
- Repository 에 저장할 문서 목록

## Assets 내 폴더 

- 아래 폴더의 형태에 맞게 사용.
- 추가 폴더가 필요할 경우 협의하에 추가
- 개인 작업물은 필히 `WorkSpace`에서 작업할 것.

| 폴더명 | Description |
|--|--|
| ImportAssets | 외부 에셋 추가 |
| Scripts | 스크립트들 |
| Metarials | 외부 에셋 이외의 메테리얼 |
| Animations | 애니메이션들 |
| Scenes | 씬 모음 |
| Plugins | 추가 플러그인 모음 |
| WorkSpace | 개인 작업 공간 |
