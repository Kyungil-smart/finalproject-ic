# StaffEvent 시스템

## 개요
프로젝트에 투입된 직원들의 DISC 값 합산으로 조합를 판단하여 이벤트를 발생

## 동작 방식
1. 투입된 직원들의 DISC 값 합산
2. 합산 값으로 조합 등급 판단
   - 좋은 조합
   - 평범한 조합
   - 나쁜 조합
3. 조합 등급에 맞는 이벤트 선택
4. UI 표시 및 버튼 클릭 대기
5. 결과 반영

## DISC 기준
| 등급 | 조건 |
|------|------|
|   D  |   1  |
|   I  |   2  |
|   S  |   4  |
|   C  |   8  |

## 조합 기준
| 등급 | 조건 |
|------|------|
| 좋은 조합 | 합산 6, 9 |
| 적당한 조합 | 합산 2~4, 8~16 |
| 나쁜 조합 | 합산 5, 10 |

## 주의 사항
- 이벤트 테이블에 따르면 이벤트 조합이 구분이 되어 있지 않아 구분할 필요가 있음.
- 선택 이벤트 같은 경우 이로운 효과와 해로운 효과가 둘다 있으므로 결과반영이 중요함
- 좋은 조합을 제외한 나머지 2종류의 조합은 선택지가 있음(이지선다)
