# 개발 과정에서의 AI 활용기

## 들어가며

이 프로젝트는 개발 과정에서 AI(Claude)를 적극적으로 활용했습니다.
다만 "코드를 대신 작성해주는 도구"로 쓰기보다는, **설계 구조를 함께 잡고,
아이디어를 발전시키고, 문제를 다각도로 분석하는 협업 파트너**로 활용한 것이
핵심입니다.

AI는 만능이 아닙니다. 하지만 사람이 방향을 잡고 AI가 폭넓게 가능성을
제시하며 서로 검증하는 방식으로 협업했을 때, 개발 생산성과 문제 해결
속도가 크게 올라간다는 것을 이번 프로젝트에서 경험했습니다.

---

## 1. 구조 설계 파트너로서의 활용

가장 큰 활용처는 **시스템 구조를 설계하는 단계**였습니다.
구현에 들어가기 전에 "이 시스템을 어떤 구조로 나눌 것인가"를 AI와 함께
논의하면서, 여러 설계안의 장단점을 비교하고 방향을 정했습니다.

- **저장/불러오기 시스템(SaveManager)**
  게임 상태를 어디까지 저장할지, 어떤 단위로 데이터를 캡처하고 복원할지를
  함께 정리했습니다. 각 매니저가 자기 데이터를 스스로 저장/복원하는
  구조(Capture/Restore)로 방향을 잡고, 저장 대상 목록을 하나씩 검토했습니다.

- **스태프(직원) 시스템의 리소스 관리 구조**
  캐릭터 썸네일과 프리팹을 어떤 규칙으로 키를 부여하고 매핑할지,
  어드레서블 에셋 관리 규칙을 설계하는 과정을 함께 논의했습니다.

이 단계에서 AI는 코드를 짜주는 존재가 아니라, **"이렇게 나누면 이런
트레이드오프가 있다"를 빠르게 정리해주는 화이트보드**에 가까웠습니다.

---

## 2. 브레인스토밍 · 아이디어 검증

기능을 어떻게 구현할지 막막할 때, AI와 대화를 주고받으며 아이디어를
구체화하는 방식으로 활용했습니다.

- 스태프 채용 후보를 생성할 때 중복을 어떻게 막을지
- SPUM 기반 캐릭터의 애니메이션을 어떤 방식으로 제어할지

이런 주제들을 놓고 "이런 접근은 어떨까?"를 던지면 AI가 여러 갈래의
가능성을 펼쳐주고, 그중 우리 프로젝트 맥락에 맞는 것을 사람이 골라
발전시키는 흐름으로 진행했습니다. 최종 판단과 구현은 항상 사람의 몫이었지만,
**초기 아이디어의 폭을 넓히는 데** AI가 큰 역할을 했습니다.

---

## 3. 트러블슈팅에서의 협업 — AI와 사람의 역할 분담

AI 협업의 한계와 가치를 동시에 보여준 사례가 있습니다.

**증상**: 특정 상황에서 이미지가 정상적으로 로딩되지 않는 이슈가 발생했습니다.

**AI의 초기 진단**: AI는 이 문제를 **어드레서블(Addressable) 에셋 로딩
관련 이슈**로 판단하고, 그 방향의 해결책들을 제안했습니다. 논리적으로
타당한 접근이었고, 여러 방법을 시도해봤습니다.

**실제 원인**: 하지만 여러 시도에도 해결되지 않았고, 최종적으로 사람이
직접 여러 방면을 확인해본 결과 원인은 코드가 아니라 **스마트폰
애플리케이션의 데이터 및 캐시 문제**였습니다. AI가 제안한 코드 레벨의
접근으로는 닿기 어려운 영역이었습니다.

**교훈**:
AI는 만능이 아닙니다. 실행 환경(단말기의 캐시·저장소 상태 등)처럼
코드 바깥에 있는 원인은 AI가 직접 확인할 수 없기 때문에, 잘못된 방향으로
진단할 수도 있습니다.

그러나 이 과정이 무의미했던 것은 아닙니다. AI가 코드 레벨의 가능성들을
빠르게 소거해준 덕분에, **사람은 "코드가 아니라 다른 곳에 원인이 있다"는
쪽으로 더 빨리 눈을 돌릴 수 있었습니다.** AI가 폭넓게 후보를 좁히고
사람이 실제 환경에서 최종 확인하는 **역할 분담**이 이루어졌을 때,
트러블슈팅이 훨씬 효율적으로 마무리되었습니다.

---

## 정리

| 활용 영역 | AI의 역할 | 사람의 역할 |
|---|---|---|
| 구조 설계 | 설계안·트레이드오프 정리 | 최종 구조 결정 |
| 브레인스토밍 | 아이디어 폭 확장 | 맥락에 맞는 선택·구현 |
| 트러블슈팅 | 가능성 후보 제시·소거 | 실제 환경 검증·최종 판단 |

AI를 "정답을 주는 도구"가 아니라 **"함께 생각하고 검증하는 동료"**로
대할 때, 그 가치가 가장 잘 발휘되었습니다.

---

## 여담

개발을 하며 문서 정리하는 것은 중요하지만 매우 어려운 일중 하나 입니다.
AI 를 이용하여 문서의 기본 구조에 대해 제안을 받고, 해당 문서를 체워가는 형태도로 작업을 하였습니다.
현재 이 문서도 그렇게 하여 완성하였습니다.
