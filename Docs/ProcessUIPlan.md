# Process UI Plan

만들어야 하는 Process 별 UI 와 데모/CBT 단계에서 만들 것들에 대한 우선순위를 정한다.

| Process UI Name | 마일스톤 | 우선순위 | 설명 |
|--|--|--|--|
| 프로세스 진입 알람 UI | 데모 | 높음 | 프로세스 변경시 관련 알람을 보여줄 UI |
| 직원 관리 리스트 UI | CBT | 높음 | 회사내 직원에 대한 정보를 간략히 보여줄 수 있는 리스트형 UI |
| 직원 관리 상세 UI | CBT | 낮음 | 직원 한명에 대한 정보를 상세히 볼 수 있는 UI - 필요시 진행 |
| 직원 고용 UI | CBT | 높음 | 고용을 위한 직원의 능력치 확인 및 직원 선택 |
| 시장 조사 UI | 데모 | 높음 | 장르, 테마 등에 대하여 확인 수 있는 UI |
| 장르/테마 UI | 데모 | 높음 | 장르, 테마 등에 대하여 선택할 수 있는 UI |
| 프로덕션 UI Part1 | 데모 | 높음 | 프로덕션이 진행되는 애니메이션 을 출력할 UI. 데모에서는 간단히 팝업만 진행 |
| 프로덕션 UI Part2 | CBT | 높음 | 프로덕션이 진행되는 애니메이션 을 출력할 UI. 애니메이션 추가 |
| QA UI | 데모 | 높음 | QA 미니 게임 진입 전 및 완료 후 출력 UI |
| 마케팅 선택 UI | 데모 | 높음 | 마케팅 방법 출력 및 선택 UI |
| 마케팅 진행 UI | CBT | 높음 | 마케팅 진행 애니메이션 출력 UI |
| 마케팅 결과 UI | 데모 | 높음 | 마케팅 진형 결과 리포트 UI |
| 출시 유저 및 평론가 반응 UI | CBT | 높음 | 유저 및 평론가의 반응을 확인할 수 있는 UI |
| 매출 발생 UI | 데모 | 높음 | 발생된 매출에 대한 정보를 보여줄 UI |
| 어워즈 선정 UI | CBT | 높음 | 어워즈 선정 애니메이션 및 결과를 띄워줄 UI |
